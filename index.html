Blair


This screenshot was taken with the open source program "Flameshot". My monitors are large and the screenshot itself came out to be at least 1k px in size. I resized it in the default photo editor I have in order to save bandwidth and screen estate.


When naming the screenshots I took, I named each file miumiu (the company name) and what order I took it in. Generally, I think its good practice to keep all like images in similar naming schemes and in order of use. The relative path of the images - which are all uploaded and contained in an image folder - here were used to display the images.


Not only did I resize the images to try and prevent drowning out the smaller text, I also utitlized line breaks between each image and line of text. While captioning may be a good idea for this in the future, this is the body of the text, so there isn't any reason to go the extra mile right now.


Lastly, I included alt text in all of the images. Alternative descriptions are a skill I'm somewhat familiar with. I know several blind people online as I'm hard of hearing. I don't think I'm the greatest at it, but I'm not completely lost with how to begin describing an image. It does get difficult with more complex pieces or when there's a character limit to a comic strip I'm trying to describe.
